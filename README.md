# ML6: Снижение размерности и разреженные признаки (`ML6_dimensionality-reduction-and-sparse-features`)

Практический проект по машинному обучению, посвященный исследованию и применению методов уменьшения размерности, а также эффективной работе с большими разреженными матрицами. В работе рассмотрены теоретические основы проклятия размерности, проведено сравнение линейных и нелинейных подходов (PCA, SVD, NMF, UMAP) и выполнено прогнозирование на разреженных данных датасета **Book-Crossing**.

---

## 1. Содержание и структура проекта

1. **Теоретический анализ:**
   - Исследование влияния проклятия размерности на различные классы алгоритмов (KNN, линейные модели, ансамбли, SVM).
   - Сравнение математических особенностей и областей применения методов **PCA / SVD**, **NMF** (неотрицательное матричное разложение) и **LLE** (локально линейное вложение).
2. **Работа с разреженными признаками (Book-Crossing):**
   - Построение разреженной матрицы взаимодействия пользователей и книг (`scipy.sparse.csr_matrix`).
   - Подготовка данных для задачи регрессии — предсказания возраста пользователей по их рейтингам.
   - Сравнение моделей **Ridge Regression** и **Random Forest** на трех пайплайнах:
     - Исходные разреженные признаки.
     - Признаки после снижения размерности с помощью **TruncatedSVD**.
     - Признаки после нелинейного уменьшения размерности с помощью **UMAP**.
3. **Визуализация многомерных данных:**
   - Подготовка пайплайнов для проекции и визуализации данных высокой размерности на примере датасета **MNIST**.

---

## 2. Анализ результатов и выводы по моделям

- **Влияние размерности:** Высокая разреженность и многомерность данных значительно увеличивают вычислительную сложность алгоритмов расстояний и могут приводить к переобучению моделей без предварительной фильтрации или сжатия признакового пространства.
- **Сравнение подходов к редукции:** 
  - Линейные методы (**TruncatedSVD**) эффективно справляются с разреженными матрицами большого размера и сохраняют глобальную структуру данных.
  - Нелинейные методы (**UMAP**) позволяют лучше улавливать локальные структуры и сложные нелинейные зависимости, однако требуют больших вычислительных затрат.
- **Качество моделей:** Использование уменьшенных признаковых пространств позволяет ускорить обучение моделей (`Ridge`, `Random Forest`) при сохранении сопоставимого уровня качества метрик ($R^2$).
